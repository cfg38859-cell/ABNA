# داده و پشتیبان

## محل ذخیره
همه‌چیز در `localStorage` همان مرورگر/اپ است. هر «مجموعه» یک کلید با پیشوند `hdb_` دارد که یک شیء JSON (شناسه ← رکورد) نگه می‌دارد.

| کلید | محتوا |
|---|---|
| `hdb_members` | اعضا |
| `hdb_att` | حضور و غیاب هیئت/حلقه |
| `hdb_disc` · `hdb_prz` | موارد انضباطی · جوایز |
| `hdb_inv` · `hdb_inv_fb` | دعوت‌ها · نظرها |
| `hdb_sugg` | انتقاد و پیشنهاد |
| `hdb_ac_people` · `hdb_ac_tx` · `hdb_ac_att` | آکادمی: افراد، شهریه/پرداخت، حضور |
| `hdb_kh_people` · `hdb_kh_tx` | خدام: افراد، بدهی/پرداخت |
| `hdb_cash` · `hdb_debts` · `hdb_loans` · `hdb_st` | ورودی/خروجی · بدهی‌ها · وام‌ها · ایستگاه صلواتی |
| `hdb_st_staff` · `hdb_st_disc` | ایستگاه: خادمین، انضباطی |
| `hdb_auth` | حساب‌ها |
| `hdb__arch` · `hdb__del` | بایگانی حضور و علامت رکوردهای حذف‌شده (برای ادغام درست) |
| `hdb_bk_log` | گزارش فعالیت پشتیبان |
| `heyat_user` · `fp_map` | کاربر فعلی · نگاشت اثر انگشت |
| `bk_last` · `bkfp_*` | زمان آخرین پشتیبان · رمز ذخیره‌شدهٔ پشتیبان سریع |
| `theme_i` · `theme_c` · `ui_k` | تم، رنگ دلخواه، شکل صفحهٔ اصلی |
| `ac_dm_tpl` | قالب پیام بدهی آکادمی |
| `app_html` · `app_ver` | نسخهٔ نصب‌شده از بخش «به‌روزرسانی» |

> فهرست مجموعه‌ها در `CL` و برچسب‌هایشان در `LB` (در `src/js/main/60-core-members-backup-themes.js`) تعریف شده است.

## فرمت فایل پشتیبان
متن `HEYAT1.<salt>.<iv>.<cipher>` (همه Base64):
- کلید: PBKDF2‑SHA256 با ۱۵۰٬۰۰۰ تکرار از رمز حساب و `salt` تصادفی ۱۶ بایتی
- رمزنگاری: AES‑256‑GCM با `iv` تصادفی ۱۲ بایتی
- متن رمزگشایی‌شده JSON است: `{ v:3, ver, at, by, d:{ مجموعه: {...} } }`

**رمز را گم نکنید**؛ بدون رمز، فایل پشتیبان قابل بازیابی نیست.

## نکتهٔ مهم برای تغییر کد
اگر ساختار رکوردها را عوض می‌کنید، باید پشتیبان‌های قدیمی (`v:3`) هنوز وارد شوند. قبل از انتشار، با یک پشتیبان واقعی آزمایش کنید (قالب PR همین را یادآوری می‌کند).
