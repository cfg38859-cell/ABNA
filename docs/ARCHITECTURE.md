# ساختار فنی

## اصل کار
برنامه یک **فایل HTML تکی** است (HTML + CSS + JS + فونت + لوگو). برای اینکه نگهداری‌اش ممکن باشد، این پروژه آن فایل را به قطعه‌های کوچک شکسته و هنگام ساخت (`npm run build`) دوباره می‌چسباند. چون هیچ بسته‌بندی‌کننده (webpack/vite) در کار نیست، خروجی دقیقاً همان کدی است که نوشته‌اید.

```
src/index.template.html ──┐
src/css/*.css            ─┤  build/build.mjs  ──►  dist/heyat-offline.html     (تک‌فایل)
src/js/*.js, src/js/main ─┤                   ──►  dist/web/                   (PWA)
src/assets/*             ─┘                   ──►  dist/android-www/           (Capacitor)
```

## توکن‌های قالب
| توکن | معنی |
|---|---|
| `{{inline:js/x.js}}` | محتوای فایل را همان‌جا بگذار |
| `{{inline-dir:js/main}}` | همهٔ فایل‌های پوشه را به ترتیب نام پشت هم بگذار |
| `{{asset:assets/logo.webp}}` | فایل را Base64 کن و به‌صورت `data:` URI بگذار |

**ترتیب مهم است.** بسیاری از اسکریپت‌ها به هم وابسته‌اند (مثلاً `window.show` در فایل اصلی تعریف می‌شود و فایل‌های بعدی آن را دور می‌زنند). ترتیب در `src/index.template.html` و پیشوند عددی نام فایل‌ها حفظ شده است؛ آن را جابه‌جا نکنید.

## ترتیب بارگذاری (خلاصه)
1. `00-quick-backup-button` · `01-backup-log` — پشتیبان سریع و گزارش فعالیت
2. `02-self-update-loader` — `APP_VER` و بارگذاری نسخهٔ نصب‌شده از بخش «به‌روزرسانی» (اگر نسخهٔ ذخیره‌شده جدیدتر باشد، صفحه را با `document.write` جایگزین می‌کند)
3. `03-jalali-helpers` — سال کبیسهٔ شمسی و طول ماه
4. `04-finance-engine` — `HFC`: موتور واحد محاسبهٔ مالی (برای صفحهٔ مالی و داشبورد)
5. CSS ها (پایه ← polish v35 ← رنگ دلخواه ← دسکتاپ)
6. `05-storage-layer` — لایهٔ ذخیره‌سازی روی `localStorage` که جای پایگاه‌دادهٔ آنلاین قدیمی (`claude.use('db')`) را می‌گیرد
7. **`js/main/*`** — هستهٔ برنامه (شکسته‌شدهٔ یک اسکریپت ۱۸۰ کیلوبایتی):
   | فایل | محتوا |
   |---|---|
   | `00-home-and-navigation` | شبکهٔ صفحهٔ اصلی، `show()`, صفحهٔ شروع |
   | `10-attendance` | حضور و غیاب هیئت/حلقه، ثبت عضو، گزارش، Word/Excel |
   | `20-finance` | امور مالی (۸ تب)، PDF ایستگاه، مغایرت‌گیری |
   | `30-suggestions` | انتقاد و پیشنهاد |
   | `40-discipline` | موارد انضباطی |
   | `50-invitations` | دعوت مداحان و سخنرانان + نظردهی |
   | `60-core-members-backup-themes` | اعضا، لیست، جوایز، داشبورد، حساب‌ها، پشتیبان، به‌روزرسانی، تم، اصلاحیه، آکادمی، گزارش‌ها، مسیریابی |
8. `06-escape-key` · `07-station-section` · `08-quick-backup-fingerprint` · `09-swipe-navigation` — افزودنی‌ها (بعد از هسته چون به آن وصل می‌شوند)

> ردیف‌های بخش‌های مختلف `js/main` هرکدام یک IIFE مستقل‌اند و به هم فقط از طریق `window.*` (مثل `window.show`, `window.openFin`) و DOM وصل می‌شوند.

## افزودن یک بخش جدید
1. فایل `src/js/NN-نام.js` را بسازید (یک IIFE که به `window.openXxx` متصل می‌شود).
2. در `src/index.template.html`، بعد از اسکریپت‌های هسته یک خط اضافه کنید:
   `<script>{{inline:js/NN-نام.js}}</script>`
3. بخش را در شبکهٔ صفحهٔ اصلی ثبت کنید (به الگوی `07-station-section.js` نگاه کنید: دکمه را به `#grid` اضافه می‌کند).
4. اگر داده ذخیره می‌کند، نام مجموعه را به `CL` و `LB` در `60-core…` اضافه کنید تا در پشتیبان بیاید.
5. `npm test` و `node build/bump.mjs`.

## نسخهٔ وب (PWA)
- `manifest.webmanifest`: نصب روی صفحهٔ اصلی، حالت تمام‌صفحه.
- `sw.js`: صفحهٔ اصلی «اول شبکه، بعد حافظه»؛ بقیه «اول حافظه». شناسهٔ حافظه از شمارهٔ نسخه و هش خروجی ساخته می‌شود؛ با هر ساخت جدید، حافظهٔ قدیمی پاک می‌شود.
- فقط روی `https` (یا `localhost`) ثبت می‌شود؛ روی `file://` ثبت نمی‌شود و ضرری هم ندارد.

## نسخهٔ اندروید
Capacitor همان `dist/android-www/index.html` را در یک WebView اجرا می‌کند. تفاوتش با وب فقط یک اسکریپت کوچک است (`src/native/android-shim.js`) که **قبل از کد برنامه** اجرا می‌شود:
- `a.download` با آدرس `blob:` ← ذخیره در حافظهٔ موقت + برگهٔ اشتراک‌گذاری اندروید (پشتیبان، PDF، Word/Excel، VCF)
- `navigator.share` برای متن (اگر وجود نداشت)
- `window.close()` ← `App.exitApp()` (برای «بله، خروج»)
در مرورگر و PWA هیچ اثری ندارد.

## بررسی‌ها (`npm test`)
نبودن توکن جایگزین‌نشده · درستی نحوی همهٔ اسکریپت‌ها (با `vm.Script`) · وجود عناصر کلیدی · جاسازی فونت و لوگو · نبود وابستگی بیرونی (آفلاین‌بودن) · هم‌خوانی `APP_VER` با `package.json` · صحت manifest، آیکون‌ها و service worker · وجود پل اندروید قبل از کد برنامه.
